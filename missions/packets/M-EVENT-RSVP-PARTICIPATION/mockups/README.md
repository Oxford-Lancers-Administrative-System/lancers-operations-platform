## Review coverage

The review build currently exposes these surfaces without a decision gate:

- event list and calendar;
- create/edit event;
- event draft;
- audience and approval;
- approved and queued;
- live responses;
- delivery diagnostics;
- attendance board;
- Player attention queue;
- Monday report;
- private event RSVP;
- personal **My RSVPs** page; and
- event-type RSVP defaults.

Every surface is labelled **Existing**, **Modified** or **New**. The current Material UI shell,
route architecture and established workflows are the baseline. New work must be visually and
behaviorally integrated into those pages rather than treated as a standalone product.

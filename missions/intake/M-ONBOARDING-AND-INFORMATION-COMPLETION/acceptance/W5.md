## The one locked at its recommendation

`readFieldProvenanceIn` returns `null` for a value nobody set through the
application — seeded, or arriving in a `W1` import. The specification recommended
that a player's own statement wins there, because nobody attributable asserted
the old value and `W1` already refuses to let the import file overwrite a
person's own facts. Brian approved the specification as written without
separating that row, so it is recorded as locked at the recommendation, the same
convention `W3` and `W4` used.

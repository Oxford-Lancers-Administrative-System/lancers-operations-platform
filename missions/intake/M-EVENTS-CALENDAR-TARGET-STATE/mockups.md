# Mockups

The approved mockups live with the packet, not here, so there is exactly one
copy of each:

    missions/packets/M-EVENTS-CALENDAR-TARGET-STATE/mockups/

`index.html` there lists all eight workflows and their 37 screens. Open it from
a local checkout — GitHub serves HTML as source rather than rendering it.

Each screen carries its ID (`W3-02` and so on), which is the vocabulary every
feedback item in `state.json` and every acceptance record uses.
